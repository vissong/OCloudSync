# 验证范围与证据边界

## 可复现的自动化检查

运行 `bash scripts/ci.sh`，或查看 [GitHub Actions](https://github.com/vissong/OCloudSync/actions/workflows/build.yml)。0.9.0 的构建包含 94 项 Swift 测试、网页适配器模拟、生产方法提取的 PhotoKit/调度故障回归、合成 Live Photo 转换、Release 构建、签名及 ZIP 校验。

合成媒体现场生成，不包含个人照片；测试不登录 OPPO、不读取个人照片图库、不验证真实 iCloud 服务端上传。秘密扫描独立工作流见 [CI 说明](CI.md)。

## 已进行的人工验证

维护者在本人 macOS / Apple Silicon 环境验证过：官方登录与重启会话恢复、历史基线不导入、增量检查、原文件下载、图库查重、实况配对导入、视频兼容处理、拍摄日期修复及队列/缓存控件。这里只保存结论与方法，不公开原片、文件哈希、图库标识、真实相册规模或会话运行明细。

这些检查仅证明所用样本和环境中的结果，不代表所有 OPPO 固件、账号地区、macOS 版本或编码变体都支持。单次本机导入成功不代表 iCloud 服务端完成上传；应在系统“照片”中查看同步状态。

## 尚未覆盖

- 最低 macOS 版本、Intel 与更多系统版本的持续回归矩阵。
- 所有 OPPO 地区服务、固件和实况封装的真实账号兼容性。
- Developer ID 签名、公证和面向普通用户的升级流程。
- iCloud 服务端逐项上传完成状态。

公开问题请使用合成样本并遵守 [隐私说明](../PRIVACY.md)。历史版本中的验证记录代表当时范围；当前文档清理不等于改写 Git 历史。
