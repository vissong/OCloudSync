# 下载速度（0.6.1）

## 需求与方案

从 OPPO 云相册下载原文件时，在同步概览、任务记录、按时间导入页面显示当前文件的下载速度、已下载量／文件总量及进度条；照片、实况照片和独立视频共用现有下载路径。

读取 WebKit `WKDownload.progress.completedUnitCount` 的真实接收字节，每 0.5 秒采样，以最近约 3 秒的字节增量计算平均速度，使用单调时钟。准备请求时显示“等待下载…”，接收开始后显示 KB/s 或 MB/s；持续无新数据时降为 0 B/s，不保留上一次的高速读数。休眠或长时间调度中断后重新采样。

速度只覆盖 OPPO 到本机的下载过程。结束、失败、取消或会话失效时立即清除；每个文件及每次重试重新计数，旧下载的迟到更新不能覆盖新任务。不改变下载、校验、缓存、去重或图库导入行为，也不把 iCloud 上传当作可测量的下载。

## 验证计划

- 使用可控字节计数及时间验证速率、停顿、未知总量、计数重置及长时间采样间隔。
- 验证监测器对结束、取消和新旧下载交替的清理与隔离。
- 编译三处界面，运行现有 CI 和独立代码审查；安装后确认显示及下载结束后的清理。

## 本地验证结果

- 70 项 Swift 测试通过，含新增 4 项速度／进度测试：滚动速率、停顿归零、采样重置、未知总量、结束清理和旧下载隔离。
- `scripts/ci.sh` 全部通过：网页适配、会话、取消、扫描、照片／视频／实况导入、日期修复及日期范围回归，签名和 ZIP 校验均通过。
- 独立审查结论：无问题。
- 0.6.1（build 10）已安装启动；升级后台账内容完全一致，自动同步仍关闭。实际云端样本检查在读取 OPPO 清单时超时，重新加载并重试后仍未进入下载，故尚未完成真实云端测速验收；不把合成计数测试视作真实网络测速。
