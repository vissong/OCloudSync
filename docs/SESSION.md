# 0.3.1 后台会话续期

2026-10-12，本机 macOS / Apple Silicon 验证。

## 原因与实现

此前 Cookie 钥匙串持久化解决的是退出后恢复。官方网页 df4c 模块仅在鼠标移动时以 60 秒节流触发续期；无人操作的后台同步缺少独立续期。此次掉线后实际进入了官方登录页，但没有历史响应日志，因此不能把该次失效唯一归因于空闲超时。

现在原生调度独立于照片扫描，每约 60–75 秒复用官方 ccde 请求客户端与 9ca4.refresh 配置。2ca3 官方路由使用 ck-rest-cn/sg/in.oppo.com 地区服务；仅精确允许已确认的生产 HTTPS origin 与固定续期路径。凭据由官方页面附加，不传回原生诊断或日志。

成功续期保存最新 Cookie。403 或官方登录页暂停云端任务；网络失败按 30/60/120/240/300 秒退避；接口异常单独提示并等待 300 秒。40 秒等待上限和 5 秒网页求值上限避免无限等待；卡住的页面先按退避重载，下一轮重新扫描再下载。关闭自动同步停止后台续期；手动检查仍可恢复。页面跳转隔离旧回调，官方 401 自动导航不会清除退避。
