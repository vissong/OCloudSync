# 架构与设计边界

当前行为见 [使用指南](USER-GUIDE.md)，演进见 [更新记录](../CHANGELOG.md)。

## 数据流

OPPO 官方页面 → WKDownload 原文件缓存 → 格式/完整性校验 → 必要的实况或视频兼容转换 → 图库查重 → PhotoKit 导入 → 系统 iCloud 照片同步。

- SwiftUI/AppKit 负责交互与调度；WKWebView 保持独立官方会话，适配器复用页面的签名和加密能力，不导出账号凭据。
- `SyncCore` 管理基线、资产版本、重试、日期、格式校验与缓存策略；原生 worker 负责 Live Photo 转换。
- 原文件下载最多预取下一项；图库查重、回执写入和提交顺序执行。
- 原子 JSON 台账与进程锁阻止并发覆盖；PhotoKit 提交前保存占位标识，结果未知时先恢复核对，不盲目重复导入。

## 同步规则

首次成功扫描分别建立照片/视频历史基线；新增按账号、资产 ID 和内容版本识别，不以拍摄日期判断。日常比较首批版本及总数，变化、待处理任务或手动请求触发完整核对，每日完整核对覆盖首批之外变化。

按时间导入是独立的显式选择：完整预览后再次验证账号与选中版本，再持久化批次并入队。预览不修改基线。正常查重按同媒体类型、同文件名与同拍摄秒；不确定提交恢复保留严格的资源/回执校验。

## 文件与日期

- 静态原图与独立视频优先保留原文件；适配失败不修改云端资源。
- 受支持实况会重编码为 HEIC/H.264 配对，保留原件；转换失败可提取静态 JPEG，取消和未知图库提交不触发回退。
- 部分 HEVC 封装生成经校验的无损兼容副本；保存原文件与实际导入文件的哈希。
- 日期优先云端拍摄时间，回退可靠原文件元数据，绝不采用下载时间。已有日期修复只操作本 App 确认拥有且有匹配回执的资产。

## 停止与清理

停止后等待当前操作安全结束。清空队列取消剩余任务但保留历史和回执；清空缓存仅操作本机 originals，允许以后重新下载，运行中禁止清理。云端原件和系统照片图库不会因队列/缓存清理而删除。

## 验证

离线测试涵盖扫描完整性、日期边界、队列/重试、下载取消、回执恢复、转换与清理；真实账号检查和单机结果不作为所有设备的兼容承诺。详见 [验证边界](VALIDATION.md)、[CI](CI.md) 和 [贡献指南](../CONTRIBUTING.md)。
